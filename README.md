# Nadeesha Academic Portfolio

A calm, mobile-friendly academic portfolio for GitHub Pages.

## Files

- `index.html` - main homepage
- `publications.html`
- `awards.html` - separate publications page with search and filters
- `style.css` - design and responsive styling
- `script.js` - mobile menu and publications filtering
- `profile.jpg` - add your profile picture using this filename
- `cv.pdf` - add your CV using this filename

## GitHub Pages setup

1. Create a repository named `yourusername.github.io`.
2. Upload all files in this folder to the repository root.
3. Go to Settings > Pages.
4. Select branch `main` and folder `/root`.
5. Save.

Your website will be live at `https://yourusername.github.io`.

## Editing publications

Open `publications.html` and duplicate a `publication-card` block. Update title, authors, venue, year, type, tags, and links.


## Pages
- `index.html` — homepage
- `publications.html`
- `awards.html` — separate publications page
- `research.html` — separate research page with interests, thesis, ongoing projects, and completed projects

- `experience.html` — separate academic, industry, and leadership experience page.
